### 👨‍💻 About Me

I'm **Kartik Gupta**, a **3rd-year B.Tech Computer Science student at JSS Academy of Technical Education, Noida**.

I work across **AI/ML, Computer Vision, backend engineering, and full-stack development**. My goal is to understand systems deeply enough to design them, build them, and optimize them — not just make demos work.

Over the last year, my work has moved from standard web development and ML projects toward **production-oriented AI systems, RAG applications, computer-vision pipelines, and scalable backend architectures**.

- 🤖 **AI/ML & Computer Vision** — practical model pipelines, image processing, detection and inference
- 🧠 **LLM & RAG Systems** — embeddings, vector search, prompting, streaming and agentic workflows
- ⚙️ **Backend & System Design** — FastAPI, Node.js, PostgreSQL, MongoDB, Redis and API architecture
- 🌐 **Full-Stack Development** — React, Next.js and production-focused application development

- Streaming AI consultant with LLM fallback

#### 🎙️ [SPEAK AI](https://github.com/kartikgupta372/Speak-AI)
**AI voice coaching platform**

- Speech analysis and transcription pipeline
- Semantic retrieval with embeddings
- LLM-generated coaching feedback
- Optimized audio processing and parallel execution
- **Engineering result:** reduced response latency from roughly **60–120s to 3–10s**
- **Stack:** FastAPI, Next.js, Supabase/pgvector, sentence-transformers, Groq, Python

A research-oriented project focused on **computer vision, tracking, simulation and prediction** for free-space optical communication terminal alignment.
