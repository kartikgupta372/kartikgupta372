### 🚀 Featured Projects

<details>
<summary><b>🛰️ AI-Enhanced Cooled Sensor IR Imaging Pipeline — DRDO SSPL</b></summary>
<br>

A production image-enhancement pipeline built during my internship at DRDO's Solid State Physics Laboratory, targeting InSb/MCT cooled-sensor thermal imagery. The final architecture is a deliberately conservative 6-step pipeline — percentile normalization → bad-pixel inpainting → NLM denoising → CLAHE → threshold-gated unsharp mask → gamma correction — chosen after aggressive enhancement methods (detailEnhance, heavy retinex) were found to amplify sensor grain rather than improve signal quality. Shipped with a Streamlit frontend for single/batch inference and a YOLOv8 detection module filtered to 18 operationally-relevant COCO classes.

| Stack | Scale | Performance | Security | Impact | Repository |
|:--|:--|:--|:--|:--|:--|
| Python, OpenCV, PyTorch, YOLOv8, Streamlit | Production pipeline for cooled IR sensor data | Conservative pipeline outperformed aggressive enhancement on quality metrics | Internal DRDO deployment — details generalized for public disclosure | Detection scoped to 18 relevant classes for operational signal | Internal / Not public (DRDO) |

</details>

<details>
<summary><b>🎙️ SPEAK AI — Real-Time Voice Coaching Platform</b></summary>
<br>

A voice coaching application combining speech transcription, semantic feedback retrieval, and LLM-generated coaching notes. The core engineering challenge was latency — the initial pipeline took 60–120 seconds per response, which made real-time coaching unusable. Rebuilt around `librosa.yin` (replacing `pyin`), a 20-second audio cap, 16kHz sampling, and `asyncio.gather` parallelization, bringing response time down to 3–10 seconds.

| Stack | Scale | Performance | Security | Impact | Repository |
|:--|:--|:--|:--|:--|:--|
| FastAPI, Next.js, Supabase pgvector, Groq (Llama 4 Scout), sentence-transformers | Full pipeline: transcription → embedding search → LLM feedback | 60–120s → 3–10s response latency | Server-side key handling, environment-based secrets | Made real-time voice coaching feedback practically viable | [Repository Link] |

</details>
